### Gabarito do Quiz

1. **Faixa salarial e metodologias de cálculo:** Em 2026, a faixa salarial de referência para um analista júnior situa-se entre R$ 3.000 e R$ 5.000 mensais. O Glassdoor aponta um salário-base médio fixo de aproximadamente R$ 4.000, enquanto o levantamento do Salário Transparente registra uma mediana total de R$ 5.064 por incluir a remuneração total anual rateada, englobando bônus e participação nos lucros.
2. **Ferramentas iniciais e suas funções:** As ferramentas são Excel (Mês 1), Power BI (Mês 2) e SQL (Mês 3). O Excel fornece a base de fórmulas e visualizações cotidianas; o Power BI permite tratar dados e construir dashboards interativos; e o SQL possibilita consultar, filtrar e extrair dados em escala diretamente de bancos de dados relacionais.
3. **Importância do GitHub e do README:** Pesquisas do LinkedIn Economic Graph indicam que 78% dos recrutadores de dados checam o GitHub dos candidatos antes de agendar entrevistas, usando-o como um currículo vivo. O arquivo README é fundamental pois atua como a primeira impressão em até 30 segundos, devendo resumir claramente o objetivo do projeto, a fonte dos dados, as tecnologias aplicadas, os insights obtidos e as instruções para execução.
4. **Cinco tipos de projetos essenciais:** Análise Exploratória de Dados (EDA), Dashboard Interativo, Pipeline de Dados (ETL/ELT), Modelo de Machine Learning e Análise SQL Complexa. Essa combinação demonstra competências que vão desde a investigação de padrões e criação de relatórios visuais até habilidades de engenharia de dados e resolução de problemas de negócio.
5. **A ferramenta Quarto no portfólio:** O Quarto é um software aberto desenvolvido pela Posit (RStudio) para criação de documentos dinâmicos (HTML, PDF, Word, Blogs) integrando texto em Markdown com blocos de código em R, Python ou Julia. Ele gera estruturas de arquivos (como .qmd e _quarto.yml) que simplificam a criação de blogs técnicos, que podem ser publicados online via GitHub Pages.
6. **Fórmula para experiências no LinkedIn:** Verbo de ação + o que foi feito + ferramenta ou contexto + resultado obtido. Esse formato substitui descrições genéricas de tarefas por realizações mensuráveis e contextualizadas.
7. **Uso estratégico da Inteligência Artificial:** A IA deve ser introduzida apenas após a consolidação de uma base técnica sólida nas ferramentas essenciais (Excel, Power BI e SQL), quando o estudante já consegue tratar e analisar dados autonomamente. Nesse estágio, a IA atua como multiplicadora de produtividade e copiloto.
8. **Live Coding vs. Take-Home Test:** O Live Coding avalia o raciocínio sob pressão, a comunicação e a resolução do problema em tempo real. O Take-Home Test é feito de forma assíncrona e foca na autonomia, na qualidade e organização do código, no tratamento de erros, nos testes e na documentação.
9. **Conduta ao travar na entrevista técnica:** Ser honesto, sem inventar respostas, e mostrar o processo de raciocínio, explicando como investigaria o problema. Dividir o desafio em etapas menores, começar por uma abordagem simples e, se necessário, pedir uma orientação pontual ao entrevistador.
10. **Conhecimento de domínio na migração de carreira:** É a experiência prática prévia acumulada em um setor específico (finanças, logística, vendas, saúde). É valioso porque oferece o contexto para fazer as perguntas corretas aos dados, identificar problemas reais de negócio e interpretar os resultados de forma estratégica.

## Glossário

- **Analista de Dados Júnior:** profissional em posição de entrada responsável por coletar, limpar, tratar, organizar, interpretar e apresentar dados para apoiar decisões.
- **Analista de Business Intelligence (BI):** profissional focado em indicadores de desempenho, modelagem de dados e relatórios gerenciais/dashboards.
- **Salário-Base:** valor fixo mensal, sem bônus, comissões, participação nos lucros ou benefícios.
- **Remuneração Total:** salário-base somado aos componentes variáveis anuais rateados por mês (bônus, gratificações, PLR).
- **Regime CLT:** contratação pela Consolidação das Leis do Trabalho, com férias remuneradas, 13º salário, FGTS e benefícios contratuais.
- **Regime PJ (Pessoa Jurídica):** prestação de serviços entre empresas; o valor recebido é faturamento bruto e o profissional gerencia tributos e custos, sem benefícios trabalhistas automáticos.
- **Excel:** planilha eletrônica usada para fórmulas (PROCV/PROCX, SOMASE, ÍNDICE e CORRESP), tabelas dinâmicas e análises.
- **Power BI:** plataforma de BI da Microsoft para conectar fontes, transformar dados (Power Query), criar cálculos (DAX) e painéis interativos.
- **Power Query:** ferramenta do Excel e do Power BI para importar, limpar, transformar e carregar dados (ETL).
- **SQL (Structured Query Language):** linguagem para consultar, manipular e relacionar dados em bancos relacionais (SELECT, WHERE, GROUP BY, JOIN).
- **DAX (Data Analysis Expressions):** linguagem de fórmulas do Power BI para medidas e colunas calculadas.
- **Python:** linguagem usada em dados para automação, manipulação, estatística e machine learning (Pandas, NumPy, Matplotlib).
- **EDA (Análise Exploratória de Dados):** etapa inicial que investiga o conjunto de dados, resume características, identifica padrões e anomalias.
- **ETL / ELT (Extrair, Transformar e Carregar):** processo de coletar dados de várias fontes, limpá-los segundo regras de negócio e carregá-los em um repositório.
- **GitHub:** plataforma de hospedagem de código com Git, usada para portfólios e colaboração.
- **Git:** sistema distribuído de controle de versão.
- **README:** arquivo de documentação (geralmente em Markdown) na raiz do repositório, que explica finalidade, dados, tecnologias e uso.
- **Quarto:** sistema de publicação técnica de código aberto (evolução do R Markdown) que intercala texto e código em R, Python e Julia.
- **GitHub Pages:** serviço do GitHub para hospedar sites estáticos a partir de um repositório.
- **Commit:** registro de alterações salvas no histórico do Git.
- **Push:** comando que envia commits locais para o repositório remoto.
- **Live Coding:** avaliação em que o candidato programa em tempo real explicando o raciocínio.
- **Take-Home Test:** desafio prático resolvido fora da entrevista, com prazo.
- **System Design:** etapa que avalia o planejamento da arquitetura de sistemas escaláveis.
- **Sistema ATS (Applicant Tracking System):** ferramenta de triagem automática de currículos por palavras-chave, formação e competências.
- **Método STAR (Situação, Tarefa, Ação, Resultado):** técnica para responder perguntas comportamentais.
- **Conhecimento de Domínio:** compreensão prática de um setor específico (varejo, finanças, saúde, logística).
- **CTE (Common Table Expression):** consulta temporária nomeada dentro de um SQL, que simplifica subqueries.
- **LEFT JOIN:** retorna todos os registros da tabela da esquerda e os correspondentes da direita.
- **INNER JOIN:** retorna apenas as linhas com correspondência nas duas tabelas.
- **FULL OUTER JOIN:** retorna todos os registros das duas tabelas, com ou sem correspondência.
